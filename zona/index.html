Zona — Stay tuned, Stay notified.

A private, multi-source notification inbox for iOS and Android. Name a source per machine or local app; alerts land in a durable seven-day inbox with push, severity levels, Live Activities, and per-source sounds. Opens ready to use: recent alerts appear immediately, stay readable offline, and resync quietly when you reconnect.

How it works

3 STEPS
  • 1 · SEND

    Any source posts an alert

    • An app, script, or AI agent sends one authenticated POST with its own source token. Idempotency keys make retries safe.
  • 2 · STORE

    The inbox keeps the record

    • A Supabase Edge Function validates the token and writes the durable inbox row. The row is the record; push is best-effort on top.
  • 3 · DELIVER

    A worker pushes to your devices

    • Push delivery retries provider failures instead of dropping alerts. Quiet hours still accept the row — only the push is held.

Details

6 ENTRIES
  • SOURCES

    Multi-source inbox

    • One source token per machine or app, so every alert is attributable and the inbox stays filterable.
  • SEVERITY

    Levels, categories, sounds

    • Alerts carry a severity from low to critical plus an optional category, with per-source notification sounds.
  • iOS

    Live Activities

    • Ongoing work surfaces on the Lock Screen and Dynamic Island while it runs.
  • OFFLINE

    Readable without a network

    • Recent alerts are cached on device and resync quietly when you reconnect.
  • ATTACHMENTS

    Images in alerts

    • Attach up to five images — screenshots, build artifacts, or charts straight to the phone.
  • STACK

    Expo · Supabase · PLpgSQL

    • React Native app built with Expo; Supabase Edge Functions ingest; a PLpgSQL worker delivers.
